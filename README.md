# Interactive Information Map Builder

Transform disorganized information from diverse sources into a clean, visual web of connected ideas using advanced artificial intelligence.

This application is designed to help you upload text documents, web articles, video transcripts, or online folders, and automatically discover how the people, places, events, and concepts mentioned in them are linked. You can then visually explore this web of connections and chat directly with your compiled knowledge.

---

## What It Can Do

### 1. Import Information from Multiple Sources
You can easily feed information into the system from various places:
* **Local Files:** Upload documents directly from your computer (such as files containing typed text or scanned reports).
* **Websites & Articles:** Point the tool to online web pages or encyclopedia entries.
* **Online Videos:** Provide links to video sharing platforms to extract spoken dialogue.
* **Cloud Storage:** Connect directly to virtual folders stored on remote cloud storage systems.

### 2. Discover Connections and Build a Knowledge Map
Once your information is imported, the built-in artificial intelligence automatically reads through it to build a visual map:
* **Identify Key Items:** It finds important subjects, such as people, organizations, locations, concepts, dates, or assets.
* **Link Related Items:** It determines how these subjects interact (e.g., who is employed by which company, which events happened at what location, or how ideas relate).
* **Cross-Document Discovery:** It automatically finds relationships between different files (e.g., connecting a person mentioned in a local text file to an event described in a web article).

### 3. Customizable Mapping Guidelines
You can direct the artificial intelligence on what kinds of details you want to focus on:
* **Define Important Topics:** Specify which categories of items (like "Product Name" or "Employee") and links (like "designed by" or "reports to") you want the system to look for.
* **Adaptive Map Generation:** Let the system find all connections automatically if you don't have a specific focus in mind.

### 4. Interactive Visual Exploration
View and play with your maps in an interactive interface:
* **Visual Map View:** See your documents represented as circles (items) connected by lines (links).
* **Multi-Source Overview:** View a combined map for several uploaded sources at the same time to see the big picture.

### 5. Chat and Ask Questions
Instead of searching through files, you can talk directly to your information:
* **Conversational Questions:** Ask questions in plain language (e.g., "What are the common interests of the people mentioned in my uploaded documents?").
* **Smart Answers:** The system reviews the connection map to synthesize accurate answers.
* **Clear Citations:** Every answer comes with links showing exactly which source document, item, or connection was used to form the response.

### 6. Usage and Limits Tracking
* **Monitor Consumption:** View a dashboard showing how much of the smart AI search capabilities you have consumed.
* **Stay Within Limits:** Check daily and monthly caps to prevent exceeding your usage allowances.
